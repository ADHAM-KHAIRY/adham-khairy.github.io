Night at the Museum | Fahemsec

Dec 22, 2025 · 5 min read
cybersecurityapiweb-security

Let’s dive straight into this cool, somewhat creative medium web challenge from FahemSec.

Challenge URL: Night at the Museum [WEB] [Medium] [300 points]

The application consists of basic authentication with role separation between users and admins. Users can purchase tickets for six rooms, while access to the seventh room — where the flag is located — is limited to admins. There is also a QR submission feature where user-generated ticket QRs are processed by an automated admin bot to validate and mark the user as a visitor.

Taking a look at the source code and file tree, there are around 89 files — yeah, that’s a lot, but we’ll get through it.

The bot’s primary role is to authenticate as an admin, scan the QR code, blindly extract the id parameter, and use it directly in the /admin/check?userId= endpoint. With that in mind, we can move on to reviewing the admin functions.

The admin routes expose three functions, with the most interesting one being /api/admin/promote/:id, which upgrades a normal user to an admin role.

At this point, if the admin bot calls /admin/check?userId= with a value like ../../../api/admin/promote/123 the endpoint /api/admin/promote/../../../api/admin/promote/123 will be called and then the backend resolves it to api/admin/promote/123. As a result, this should promote the user to admin—so let’s test it.

The next step is to take a valid QR scan JSON from a normal user, modify the id field to ../../../api/admin/promote/31, and then submit it back to the bot for scanning to see if it promotes the user to the admin role.

In the end, this challenge highlights how blindly trusting user-controlled input — especially when it’s later reused in privileged backend logic — can completely break role separation. A simple path traversal combined with an over-trusted admin bot was enough to escalate privileges and access restricted resources. Proper input validation and strict routing controls would have prevented this entire exploit chain.
