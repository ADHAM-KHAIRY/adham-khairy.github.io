[Out Of Order —Revenge ] WEB challenge — Helwan CTF

Hi — I’m Adham (aka 0xSponge). My team ( أدهم عايز يتجوز ) placed 4th in the Helwan CTF; I solved three web challenges solo. This writeup covers the first two, with clear recon, exploit POCs, and the final flags.

The first challenge, Out Of Order, is a web app with login and signup functionality. While inspecting the source code I discovered that the username field is vulnerable to SQL injection — below I'll show the vulnerable code and the tests I ran.

php
define('SAFE_MODE', false);

try {
      if (SAFE_MODE) {
        $stmt = db()->prepare('INSERT INTO users (username, email, password_hash) VALUES (?, ?, ?)');
        $stmt->execute([$username, $email, $hash]);
      } else {
        $sql = "INSERT INTO users (username, email, password_hash) 
                VALUES ('$username', CAST('$email' AS CHAR), '$hash')";
        db()->exec($sql);
      }

In the end, both Out Of Order and Revenge fell, and with them the flags. It was a fun ride, a lot of trial and error, and a great reminder that sometimes the smallest details make the biggest difference. 4th place this time — but next time, aiming for the top!
